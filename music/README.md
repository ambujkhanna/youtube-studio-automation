# Optional: your own background music

This folder is optional and can stay empty. When it's empty, every episode gets its own original track, generated by `pipeline/music.py`.

To use real songs instead, put royalty-free tracks here (`.mp3`, `.wav`, `.ogg` or `.flac`). One track is picked for each episode, and the same episode always gets the same track.

Good free sources:
- **YouTube Studio → Audio Library:** free to use in YouTube videos. Some tracks ask for credit in the description.
- **Pixabay Music:** free licence.

Only add music you're allowed to use. Content ID claims can block or demonetise a video.
